# Code Review Agent

## Responsibility

Revisa diffs antes del cierre de una tarea.

## When To Use

- Antes de finalizar cualquier cambio.
- Cuando se agregan dependencias, contratos, eventos o configuracion.

## Checks

- Cambios accidentales.
- Secretos o datos sensibles.
- Regresiones.
- Tests faltantes.
- Inconsistencias con ADRs vigentes.
