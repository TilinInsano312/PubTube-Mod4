# Software Engineering Agent

## Responsibility

Analiza, implementa y mantiene cambios de codigo en PubTube Modulo 4.

## When To Use

- Cambios en FastAPI, middleware, rutas, configuracion o tests.
- Correcciones de bugs.
- Integraciones tecnicas con gateway, eventos u observabilidad.

## Expected Output

- Cambio minimo.
- Tests o validacion proporcional.
- Trazabilidad compacta.
