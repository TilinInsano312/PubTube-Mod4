# Skill: Minimal Implementation

## Purpose

Aplicar el cambio mas pequeno que cumple el requerimiento.

## Rules

- No hacer refactors no solicitados.
- No agregar dependencias sin justificar.
- No modificar areas fuera del alcance.
- No hardcodear secretos.

## Output

- Diff acotado.
- Cambio asociado a un `CHG-###`.
