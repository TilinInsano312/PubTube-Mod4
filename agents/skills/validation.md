# Skill: Validation

## Purpose

Producir evidencia concreta para cada criterio de aceptacion.

## Rules

- Usar tests especificos primero.
- Marcar `NOT VERIFIED` si no existe evidencia suficiente.
- Registrar comando, resultado y causa principal si falla.

## Output

```text
AC1 -> PASS | FAIL | NOT VERIFIED
Validation: comando o inspeccion
```
